# Markdown 文档写作规范

本总 skill 和各子 skill 共用本页；公式与本地文件引用统一在此维护。工具位于总 skill 的 `scripts/`，不复制到各项目。只检查当前任务授权的文件，不累计问题或启动提醒程序。

## 1. 数学公式

### 推荐格式

- 行内公式用 `$...$`，分隔符内侧不留空格。例如 `$E_a=E_0+\alpha\Delta H$`。
- 独立公式用一对 `$$`，开始和结束标记各自独占一行，公式前后留空行：

  ```markdown
  $$
  k(T)=A\left(\frac{T}{T_0}\right)^n
  \exp\left[-\frac{E_a}{RT}\right].
  $$
  ```

- 需要实际显示的公式不要放在反引号或代码块中。代码块只用于展示公式源码。
- 本工作流统一使用美元分隔符；不要混用 `\(...\)`、`\[...\]`，不要用普通方括号代替数学分隔符。
- 下标、上标、希腊字母、分数等使用LaTeX表达；例如 `E_a`、`\alpha`、`\frac{A}{B}`。单位和化学式需要直立时使用 `\mathrm{...}`，公式中的文字使用 `\text{...}`。不要因格式修复改变数值、符号含义或科学结论。
- 普通金额的美元符号写成 `\$`。不支持的宏或复杂环境需在目标阅读器中确认；不要把任意HTML或绘图代码当作数学公式。

### 检查和修复

[md_math.py](../scripts/md_math.py)仅依赖Python标准库：

```bash
python3 scripts/md_math.py /path/to/report.md
python3 scripts/md_math.py /path/to/report.md --fix
```

默认只检查。`--fix`只转换明确的旧式数学分隔符和单行块公式；跳过代码，保留UTF-8、LF/CRLF。遇到未配对分隔符等错误，整份文档不做部分改写。**普通 `[ ... ]` 或没有数学分隔符的文字不会被猜测为公式**，需由作者明确标注。

工具不验证LaTeX命令是否受阅读器支持，也不检验数学含义；表格中的公式、复杂环境等仍须预览确认。它是轻量扫描，不是完整Markdown/LaTeX解析器。

## 2. 引用其他本地文件

- 以当前Markdown所在目录为基准写相对链接；聊天界面的文件入口另按界面规则处理。
- 链接名称说明文件用途；路径中的空格、括号、中文等按URL编码。不要把绝对Linux路径、`file://`或`//wsl.localhost/...`作为文档常规格式。
- 行号写在链接名称或正文，不把`:行号`拼到文件名；不承诺通用Markdown可精确跳行。
- 文档移动后重新检查。Mermaid箭头只是图示，可在图下另设普通文件链接。

```markdown
[反应定义](../data/reactions.py)
[附录](appendix.md)
[源码（第120行起）](../src/family.py)
[带空格资料](../data/example%20file.pdf)
```

[md_links.py](../scripts/md_links.py)同样仅依赖Python标准库：

```bash
python3 scripts/md_links.py /path/to/report.md
python3 scripts/md_links.py /path/to/report.md --fix
```

默认只检查，`--fix`才规范化。同一文档有任一错误就不部分改写。文件名后的行号、缺失文件、Windows盘符或无法映射的网络地址不猜测修复。

旧WSL地址的发行版由环境变量`WSL_DISTRO_NAME`或`--wsl-distro NAME`指定，不默认猜测、不跨发行版映射。保留换行，不改链接名称、标题、网页和页内锚点。

检查行内链接/图片和引用式定义；跳过代码。不覆盖全部嵌套标签、HTML、脚注、未定义引用或特殊扩展；不验证URL、页内锚点和Mermaid点击。

## 3. 交付前检查

从总 skill 所在目录执行上述命令，或使用其实际安装路径。子 skill 直接调用共享脚本。

| 验证层次 | 公式 | 文件引用 |
|---|---|---|
| 自动检查 | 分隔符和基本格式 | 相对路径、目标存在、路径编码 |
| 目标阅读器预览 | 公式实际排版正确，没有原样LaTeX乱码 | 显示链接名称，没有暴露完整链接语法 |
| 内容/行为确认 | 符号、单位、数值与原意一致 | 点击后打开正确文件 |

**不能用自动检查通过代替后两项。** 无目标GUI时准确报告“格式/路径已检查，实际预览或点击待确认”。不因工具正常退出就声称问题完全解决。

两个脚本退出码均为：0=本工具检查通过或修复完成；1=有错误/待规范项；2=文件读取或命令错误。按需修复后再运行默认检查；使用编辑器撤销或版本管理保留回退能力，工具不自动备份。
