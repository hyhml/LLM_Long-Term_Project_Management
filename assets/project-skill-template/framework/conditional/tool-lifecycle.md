# Candidate tool lifecycle

For each created or imported tool, record:

- purpose and the task that motivated it;
- inputs, outputs, dependencies, and permissions;
- validation performed and known limitations;
- security or privacy risks;
- expected reuse and maintenance cost.

Keep tools in `work/candidate-tools/` until the user chooses:

- `promote`: retain as a documented project tool;
- `archive`: preserve with the task history but do not treat as active;
- `discard`: remove only after explicit confirmation.
