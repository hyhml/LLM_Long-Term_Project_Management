# Retrieval coverage

Use the framework's coverage-reporting search tool for lightweight formal metadata search. Treat `index/` as disposable and check its status and source revision.

Every result must report what was searched, what authorized material was not searched, exclusions, truncation, and index freshness. Registry metadata search does not cover the bodies of PDFs, webpages, notes, or datasets.

For an empty result say only that no match was found within the currently searched, indexed, and authorized scope. Never convert that result into a claim that the project contains no such information.
