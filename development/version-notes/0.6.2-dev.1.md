# 0.6.2-dev.1

Development implementation of the accepted fixes for project-skill discovery and duplicate transaction-candidate entries.

## Runtime changes

- Project initialization now reports whether the generated child is discoverable from the current Codex working directory and, when it is not, gives the project root and explicit invocation for a new session.
- Initialization keeps the child project-local; it does not create a user-level copy or symbolic link.
- Transaction candidates now contain project data and derived data only. Candidate validation assembles the required runtime support files in an ephemeral directory outside the discoverable child tree.
- A successful commit removes its candidate while retaining the transaction plan and receipt.
- Legacy committed candidates can be listed through a cleanup preview and removed only by applying the exact approved preview hash. Any scope or content change invalidates that approval.

## Compatibility

Entry protocol 1, project-data schemas, package schemas, and existing compatible children are unchanged. Existing children inherit the runtime fix after `refresh-runtime`; no adapter or data migration is required. Legacy candidate cleanup is a separate, explicitly approved maintenance action.

## Regression record

Two verified external reports were classified as framework/runtime defects. Their real packages remain outside the repository; only minimized synthetic cases enter the developer suite.

- The discovery regression initially showed that initialization could succeed while the current Codex session could not discover the new project-local skill.
- The isolation regression initially showed that committed transaction candidates retained copied `SKILL.md` files, producing duplicate discoverable entries.
- The affected tests now verify discovery status, absence of user-level entries, data-only candidates, candidate removal after commit, and preview invalidation when a legacy candidate changes after approval.

Final full-suite and release evidence will be recorded in the stable 0.6.2 note and release receipt.
