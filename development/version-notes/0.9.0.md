# 0.9.0

Shared Markdown writing checks and an explicitly invoked repair-review reminder.

## Changes

- `markdown-writing.md` centralizes math delimiter and local-reference conventions. `md_math.py` and `md_links.py` default to checks; `--fix` performs bounded normalization only when no errors remain.
- `problem_reminder.py` accepts issues, records verified results and shows reminders after three failures. Observation IDs deduplicate retries; pending verification does not reset counts; passing closes a round and recurrence starts a new one.
- Child skills use the shared tools through total-skill routing. No background chat listener or automatic tool creation is installed.
- Local issue retention requires user authorization. Fresh artifacts contain no private registry, profile, project data or real cases; private data are excluded from GitHub and user archives.

## Compatibility and scope

Child entry protocol 1 and project-data schemas are unchanged. Compatible existing children inherit shared behavior without rewriting accepted project content. Native Windows Python is not supported by the issue store's `fcntl` locking; run it on Linux/WSL. Automated Markdown checks do not prove actual GUI rendering or link navigation.

Final release evidence is recorded in the release receipt. This version does not close the existing product gaps for complete child generation, project-data schema migration, parallel exploration or sustained research-tree planning.
