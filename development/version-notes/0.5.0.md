# 0.5.0

Stable release of the thin-child and multi-project isolation foundation on 2026-09-22.

## Delivered

- The total skill continues to discuss, propose, and generate project-local child skills.
- Generated children are thin explicit adapters with immutable project identity, compatibility metadata, user-owned project instructions, and project-local data.
- Project binding checks cover canonical root, project ID, revision, entry protocol, data schemas, managed hashes, and duplicate sibling identities.
- Ordinary conversations bind one project and do not switch silently.
- Explicit cross-project coordination is read-mostly and keeps proposals and commits separate per project.
- v0.4.0 children remain readable and can use an itemized, accepted, recoverable adapter upgrade without changing project revision.

## Validation and distribution

- 31 deterministic tests passed.
- Development and stable runtime skills validated.
- Two stable-runtime child projects generated and validated independently; read-mostly coordination preserved separate identities.
- The stable user archive contains 30 allowlisted files and excludes developer, test, private, and project data.
- Archive SHA-256: `6f1f9dab3ab341faa09ddf51953d5838ba2e4c4d74c6df095975531c9638608b`.

## Known non-blocking gaps

- Complete structured initialization of arbitrary initial records, relations, sources, and file mappings remains partial.
- The first real project-data schema migration engine is not implemented; unsupported schemas fail closed.
- Parallel exploration merging and automated machine-profile refresh remain deferred.
