# 0.5.0-rc.1

Release candidate for thin child skills and multi-project isolation.

## Candidate evidence

- 31 deterministic tests pass: 28 across seven core invariant modules and 3 runtime-release tests.
- Multi-project coverage includes isolated retrieval, root/ID mismatch, duplicate identity, conversation switch decisions, cross-project handoff rejection, read-mostly coordination, legacy upgrade preservation, and rollback.
- The whitelist runtime bundle builds reproducibly and generates a valid thin child whose installed framework version is injected as `0.5.0`.
- Development and generated runtime skills pass skill validation.

## Release boundary

- This candidate is implemented on `development` only.
- `main`, stable tag `v0.5.0`, GitHub release archive, and release receipt require a separate publication approval.
- No real child project has been migrated.
