# 0.4.0-rc.1

Release candidate implementing accepted ADR-0011 on top of `0.4.0-dev.1`.

## Changed

- User distributions are built from an exact runtime file allowlist.
- Every source file must be classified as runtime, developer-only, or explicitly local/generated before a release build succeeds.
- Development instructions move to development-only `AGENTS.md`; the runtime `SKILL.md` no longer exposes a development-mode route.
- The user README no longer contains developer test commands.
- The release builder supports non-mutating stable-version injection and deterministic ZIP creation.
- Feature tests verify exact output membership, unclassified and missing-file failures, stable version injection, reproducible archives, and child-skill generation from the built runtime.

## Compatibility and distribution

- Project and handoff schemas do not change from `0.4.0-dev.1`.
- Existing child skills are not modified automatically.
- `main` must be replaced from a validated runtime artifact rather than merged from `development`.
