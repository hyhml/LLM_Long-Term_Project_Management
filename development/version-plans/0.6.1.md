# Version plan: 0.6.1 lightweight interaction update

- Status: Developer design accepted; runtime not implemented
- Change weight: Design-only
- Requirements: `DATA-012`, `FLOW-009`, `ENV-003`, `FEED-003`, `GOV-008`
- Decision: ADR-0015

## Scope

- One permission covers bounded tool discovery and private environment-profile save.
- One preview approval creates either package; only new private/external reads add a prior permission.
- `.llmpack` creation and itemized project integration remain separate.
- Priority wording distinguishes loading, scheduling, and goal hierarchy.
- Existing children, project data, and v1 package formats remain compatible.

## Implementation sequence

1. Add focused behavioral tests for the four changed runtime interactions.
2. Make the smallest runtime and tool changes that satisfy them.
3. Run affected tests and the core suite.
4. Update user documentation and requirement status from observed behavior.
5. Run release gates only after the user approves publication.

Implementation details that do not change these outcomes are deliberately deferred to the implementation stage. No separate detailed design specification is required.
